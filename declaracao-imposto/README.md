# Declaração de Imposto de Renda — Excel

## Sobre o projeto

Projeto desenvolvido como parte de um desafio da **DIO (Digital Innovation One)**, com foco na construção de uma ferramenta no Excel para organizar e centralizar informações relevantes para a declaração do Imposto de Renda.

A proposta é utilizar recursos do Excel para estruturar os dados, facilitar a navegação entre as informações e explorar mecanismos de validação, contribuindo para uma experiência de uso mais organizada e prática.

## Objetivos de aprendizagem

- Aplicar os conceitos estudados nas aulas em um projeto prático.
- Explorar recursos do Excel para organização e manipulação de dados.
- Compreender a importância da validação e da padronização das informações.
- Documentar o desenvolvimento do projeto utilizando Markdown.
- Praticar o versionamento e o compartilhamento de projetos com Git e GitHub.

## Tecnologias e ferramentas

- **Microsoft Excel:** organização e manipulação dos dados.
- **Git:** controle de versão dos arquivos.
- **GitHub:** armazenamento e compartilhamento do projeto.
- **Markdown:** documentação técnica por meio do `README.md`.

## Aprendizados

Este desafio faz parte da minha jornada de aprendizado em tecnologia, reforçando conceitos de organização de dados, construção de planilhas e documentação de projetos.

Além da prática com o Excel, a atividade contribui para desenvolver uma visão mais estruturada sobre como informações podem ser organizadas e apresentadas para facilitar sua consulta e utilização.

## Contexto do desafio

Desafio proposto pela [DIO](https://www.dio.me/), com o objetivo de aplicar os conceitos apresentados nas aulas e documentar a experiência utilizando o GitHub.

---

**Observação:** projeto educacional. A planilha não substitui a conferência das informações nem as orientações oficiais da Receita Federal para a declaração do Imposto de Renda.
