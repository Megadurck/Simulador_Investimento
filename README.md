# 📊 Bootcamp — Análise de Dados no Excel com IA

**DIO + Reclame Aqui**

Repositório dedicado aos projetos e desafios desenvolvidos durante o Bootcamp **Análise de Dados no Excel com IA**, realizado pela [DIO](https://www.dio.me/) em parceria com o **Reclame Aqui**.

O objetivo desta jornada é desenvolver habilidades práticas em análise de dados utilizando o Microsoft Excel, explorando recursos de organização, tratamento, processamento e visualização de informações, além da aplicação de Inteligência Artificial como ferramenta de apoio à produtividade e à resolução de problemas.

## 🎯 Objetivos do Bootcamp

- Desenvolver habilidades de análise e interpretação de dados.
- Utilizar o Excel para organizar e estruturar informações.
- Aplicar fórmulas e funções para automatizar processos.
- Construir análises, indicadores e dashboards.
- Transformar dados em informações úteis para tomada de decisão.
- Explorar ferramentas de Inteligência Artificial aplicadas à análise de dados.

## 📚 Projetos e Desafios

Os projetos desenvolvidos durante o bootcamp estão organizados neste repositório, com seus respectivos arquivos e documentações.

Cada desafio também possui uma branch independente, permitindo acompanhar seu desenvolvimento e histórico sem misturar as implementações.

| Projeto | Diretório | Branch |

| Declaração de Imposto de Renda | `declaracao-imposto/` | `desafio-declaracao-imposto` |

| Dashboard Porsche | `Dashboard-Porsche/` | `Dashboard-Porsche` |

> Novos projetos serão adicionados a esta seção conforme o avanço do bootcamp.
